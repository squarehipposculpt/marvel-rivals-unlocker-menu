## 🧩 About

**Marvel Rivals catalog Menu** is a curated list of Marvel Rivals open-source tools:

- **Overlays** — on-screen helpers, layout notes, hero stats viewer, match tracker
- **Quality-of-Life Helpers** — skin catalog, loadout manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Match Helpers
- Match Tracker — review recent matches and stats
- Hero Stats Viewer — visualize hero performance notes
- Replay Notes — record and review match runs
- Playback Speed — adjust demo playback for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse skins, colors, sprays, MVP animations
- Custom Skin Notes — organize hero cosmetics
- Hero Highlight — improved visibility for team fights

### 🏋️ Practice Layout
- Practice Mode Notes — segment study on any map
- Camera Control — manually adjust spectator camera
- Jump Buffer Notes — chain complex maneuvers in the practice range
